This folder contains the design files of the NorthSec 2026 badge.

## Folder structure

| Folder     | Content                                           |
|:-----------|:--------------------------------------------------|
| boards     | Kicad schematics & pcb layout                     |
| datasheets | datasheets of used electrical components          |
| mechanical | Full FreeCAD 3d model of all components of flower |
